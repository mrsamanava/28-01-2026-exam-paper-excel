📊 Sales Data Analysis & Dashboard (Excel Project)
📌 Project Overview
This project focuses on analyzing a retail sales dataset using Microsoft Excel. It includes data cleaning, transformation, and visualization through pivot tables, charts, and interactive dashboards.
The goal is to extract meaningful business insights such as:
•	Category-wise sales performance 
•	Region-wise contribution 
•	Customer profitability 
•	Yearly growth trends 
________________________________________
📁 Dataset Description
The dataset contains detailed transactional sales records including:
•	Order Details (Order ID, Order Date, Ship Mode) 
•	Customer Information (Customer Name, Segment, Region) 
•	Product Details (Category, Product ID) 
•	Financial Metrics: 
o	Sales 
o	Quantity 
o	Discount 
o	Profit 
o	COGS (Cost of Goods Sold) 
•	Time-based fields (Year, Timeline)
